# Áudios do Fantasy RM Online

Coloque nesta pasta as trilhas sonoras do jogo:

- `exploracao.mp3` — música alegre e nostálgica para a tela principal, Cidade do Reino e menus.
- `batalha-epica.mp3` — orquestra de aventura e combate para Boss, Dungeon, Boss Mundial e DG da Guilda.

Use apenas áudios com direitos de uso apropriados.
